# SIRIUS — DARK EDITORIAL (концепция №3)
**Статус:** feature branch / preview, НЕ production. **Дата:** 11 ноября 2026.

## Решение
Утверждённое направление №3 воспроизведено через семантический HTML/CSS/JS:
- тёплый графит и приглушённый медно-янтарный свет;
- увеличенная SIRIUS-типографика за настоящей моделью на стуле;
- шесть редакционных блоков с варьированием масштаба изображений и ритма;
- UX из №2 только для тарифов, разделения аренды и фотосессии, записи.
- мягкий CSS-свет без тяжёлых WebGL/GSAP-эффектов;
- дизайн адаптирован под 360–1440 px, предусмотрен prefers-reduced-motion.

### Архитектура проекта
Сохранили исходный стек: index.html + styles.css + script.js. Никакой фиктивной React-архитектуры и статичного скриншота вместо интерфейса. Существующие реальные фотографии из \`assets/img/responsive\` используются без AI-подмены. Текущие рабочие переходы WhatsApp, VK, Яндекс Карт сохранены/перенаправлены на реальные источники.

### Чего не хватает для 1:1 достоверной реализации №3
1. Реальной фотографии пустой студии с общим планом (желательно 2400×1600 или выше, горизонтально, пространство для размещения текста слева, свет на правой части). Нельзя выдавать AI-интерьер за существующий.
2. Деталей реальной локации: софтбоксы, оборудование и гримёрная зона (3–5 кадров, от 1600 px).
3. Фотографий актуальных сезонных декораций (2–4 кадра) и подтверждения их текущей доступности.
4. Подтверждения стоимости фотосессии и характеристик оборудования.
5. Согласования использования фотографий и контактных данных для публичного сайта.

Пока вместо вымышленного интерьера показан реальный снимок из портфолио с честной подписью и ссылкой на VK с актуальными локациями. Блок можно заменить реальным фото без перепроектирования.

### Бронирование
Форма *не отправляет данные на сервер* и *не заявляет о свободных слотах*. Она готовит сообщение в WhatsApp со структурированными полями и предоставляет ссылку для повторного открытия. Реальное подтверждение времени происходит в переписке. Доступна альтернатива VK. Выбор срока аренды показывается только при «Аренда студии».

### Контакты
Карта — реальный iframe Яндекс Карт; при блокировке внешнего iframe остаётся адрес и ссылка на Яндекс Карты. Схема маршрута не выдумана.

## Контроль качества
- Chromium Playwright: 23/23 проверок на ширинах 360, 390, 768, 1024, 1440; без горизонтального overflow и JS-ошибок; изображения загружаются; проверены меню, фильтры и заявка.
- axe-core WCAG 2 A/AA + 2.1 A/AA: 0 зарегистрированных нарушений на 390 и 1440 px после исправления контраста второстепенного текста.
- Семантические ориентиры: один h1, labels у полей, aria-expanded у меню, aria-pressed у фильтров, доступность клавиатурой, alt у смысловых фото, reduced-motion.
- Превью-скриншоты \`docs/review/\`: desktop hero, mobile hero, full desktop. Сравнение с концепцией: сохранены композиционные доминанты и теплая световая диагональ; реальная студия заменена подтверждаемыми фактами, не фиктивной фотографией.
- Не тестировались реальные отправки WhatsApp/VK, корректность объявления цен заказчиком и поведение на физических iOS/Android.

### Локальная проверка
Для статического просмотра: откройте \`index.html\` в браузере или запустите \`python -m http.server 8080\` в корне. Для скриншотов нужен Playwright; например:
\`\`\`bash
PLAYWRIGHT_MODULE=/path/to/playwright-core CHROMIUM_PATH=/path/to/chrome node tests/visual-smoke.cjs
\`\`\`
Axe: установите axe-core в \`.audit-deps/node_modules\`, затем:
\`\`\`bash
PLAYWRIGHT_MODULE=/path/to/playwright-core CHROMIUM_PATH=/path/to/chrome node tests/accessibility.cjs
\`\`\`

**Запрет:** не сливать в main и не переводить Vercel в production до согласования материалов и ручной проверки preview.
